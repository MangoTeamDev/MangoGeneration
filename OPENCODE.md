# Техническое задание для ИИ: Проект "MangoGeneration"

Напиши техническую архитектуру, структуру папок и базовый исходный код для **MangoGeneration** — кроссплатформенного (Windows, Linux) FOSS-приложения для обычных пользователей. Это локальный «генератор и преобразователь всего», который решает простые бытовые задачи: генерирует обои для рабочего стола, наводит порядок в файлах и конвертирует медиаформаты.

Проект должен быть полностью автономным локальным приложением (работает без бэкенд-серверов) и использовать комбинацию из четырех языков: **Rust, Go, Python и Lua**. Каждый язык выполняет свою идеальную роль, взаимодействуя внутри одного процесса без использования сетевых сокетов (через FFI, встраивание рантаймов или вызовы CLI-процессов).

### Архитектура приложения и роли языков:

1. **Rust (Интерфейс, Система и Оркестрация):**
   * Отвечает за компиляцию в единый нативный бинарник под Windows и Linux.
   * Отрисовывает красивый, понятный обычному человеку GUI (используй `slint` или `egui`) с поддержкой Drag-and-Drop (перетаскивание файлов мышкой).
   * Отвечает за системные действия: установка сгенерированных картинок в качестве обоев рабочего стола.
   * Встраивает рантайм Lua (`mlua`) и управляет вызовами Python и Go.

2. **Python (Мозг, ИИ и Медиа-обработка):**
   * Работает как встраиваемый интерпретатор (через `pyo3`) или как фоновый процесс.
   * **Модуль генерации:** Локально создает абстрактные изображения, фракталы или стилизует картинки пользователя.
   * **Модуль "Умной уборки":** Анализирует файлы (текст, картинки, документы), понимает их суть и предлагает аккуратные имена и папки для сортировки.
   * **Модуль конвертации:** Использует легковесные библиотеки (например, `Pillow`) для изменения форматов картинок (из `.webp` в `.jpg` и т.д.).

3. **Go (Высокоскоростной Движок и Сетевой Мост):**
   * Компилируется в динамическую C-совместимую библиотеку (`.dll` под Windows, `.so` под Linux) с помощью `-buildmode=c-shared`.
   * Обеспечивает дикую скорость: параллельно в несколько потоков раскидывает гигабайты файлов при уборке или пачкой конвертирует сотни фото.
   * Если есть интернет, Go безопасно и быстро скачивает пачку красивых легальных обоев из открытых источников (например, NASA или Unsplash API).

4. **Lua (Пользовательские Сценарии и Кастомизация):**
   * Встраивается напрямую в Rust-ядро через библиотеку `mlua`.
   * Позволяет пользователю в простых текстовых файлах настраивать логику под себя. Пример: `if file.ext == 'png' then move_to('Галерея') end` или правила автоматической смены обоев по таймеру/времени суток.

### Что необходимо сделать:

1. **Структура проекта:** Покажи дерево каталогов (монорепозиторий), где логически разделены компоненты на Rust, Go, Python и Lua.
2. **Инструкция по сборке:** Напиши команды для кросс-компиляции динамической Go-библиотеки и финальной сборки нативного Rust-приложения под Windows и Linux.
3. **Исходный код (Минимально Рабочий Прототип):**
   * **Rust:** Код главного окна, которое загружает внешнюю библиотеку Go, инициализирует встроенный скрипт Lua и передает задачу в Python.
   * **Go (`engine.go`):** Код, экспортирующий C-функцию для быстрого параллельного копирования файлов.
   * **Python (`brain.py`):** Скрипт, который эмулирует генерацию простейшего графического паттерна (например, градиента) и анализирует переданный файл для сортировки.
   * **Lua (`config.lua`):** Пример конфигурационного файла с правилом: "Если сейчас вечер, отдать команду Python на генерацию темных обоев".

Пиши код на чистом, современном синтаксисе (Rust 1.97.1, Go 1.26, Python 3.14+, Lua 5.4), снабжай код комментариями. Программа должна быть на 100% легальной, безопасной и запускаться локально.
