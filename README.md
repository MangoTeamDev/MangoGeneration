# MangoGeneration

Кроссплатформенный (Windows, Linux) локальный генератор и преобразователь файлов.

- Генерация обоев для рабочего стола (градиент, паттерн, тёмные) + установка на рабочий стол
- «Умная уборка» файлов с сортировкой по папкам
- Конвертация изображений (PNG / JPEG / BMP / TGA)

Стек: Rust (GUI) + Go (движок) + C (мозг) + Lua 5.4 (правила).
